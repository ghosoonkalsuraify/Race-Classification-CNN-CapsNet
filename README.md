# Race Classification using CNN-CapsNet

A deep learning-based ethnicity classification system using:

- CNN face detection
- Automatic face cropping
- Capsule Network classification
- Streamlit web application

## Classes
- African
- Asian
- Latino

## Features
- Detects faces automatically
- Crops faces before prediction
- Predicts ethnicity from uploaded images
- Built using PyTorch and Streamlit

## Technologies
- Python
- PyTorch
- OpenCV
- Streamlit
- CNN
- Capsule Networks
